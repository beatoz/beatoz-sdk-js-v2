# Security policy

## Reporting a vulnerability

Do not open a public issue, pull request or discussion for a security problem.

Report it privately through GitHub: on this repository's **Security** tab,
choose **Report a vulnerability**
([direct link](https://github.com/beatoz/beatoz-sdk-js-v2/security/advisories/new)).

Please include:

- The affected packages and versions
- What an attacker can do, and how severe you consider it
- A minimal reproduction, or the steps to reproduce

The report stays private between you and the maintainers while it is
investigated, and the conversation continues in the advisory. Once a fix is
released, the advisory is published with credit to the reporter unless you ask
otherwise.

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes, from its first release (in development, not yet published) |
| 1.x | No - see [beatoz/beatoz-sdk-js](https://github.com/beatoz/beatoz-sdk-js) |

Only the current major receives fixes; see "Support" in [RELEASE.md](./RELEASE.md).

## Scope

This policy covers the `@beatoz/*` packages published from this repository. A
vulnerability in the chain itself belongs to
[beatoz-go](https://github.com/beatoz/beatoz-go).
